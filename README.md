# 💬 Fun Chat

**Краткое описание:**  
SPA-чат с авторизацией, списком пользователей и приватными диалогами. В проекте используется WebSocket-протокол для обмена сообщениями между клиентом и сервером в реальном времени.

**Ссылка на задание:**  
[Fun Chat Task](https://github.com/rolling-scopes-school/tasks/blob/master/stage2/tasks/fun-chat/README.md)

**Деплой:**  
[Открыть приложение](https://rolling-scopes-school.github.io/polinaromanchuk-JSFE2024Q4/fun-chat/#login)

## Технологии

- **Язык:** TypeScript
- **Фреймворк:** нет (vanilla JS + TypeScript)
- **Связь с сервером:** WebSocket
- **Сборка:** Webpack
- **Роутинг:** SPA через URL
- **Стили:** CSS
- **Форматирование:** Prettier
- **Линтинг:** ESLint
- **Git хуки:** Husky
- **Деплой:** gh-pages

## Установка и запуск

1. **Клонировать репозиторий:**

```bash
git clone https://github.com/PolinaRomanchuk/rss-stage-1.git
cd rss-stage-1
```

2. **Перейти в ветку с проектом:**

```bash
git checkout fun-chat
```

3. **Перейти в папку проекта:**

```bash
cd fun-chat
```

4. **Установить зависимости:**

```bash
npm install
```

5. **Запустить клиентскую часть в режиме разработки:**

```bash
npm run start
```

6. **Запустить серверное приложение:**

Необходимо также клонировать и запустить сервер [репозиторий](https://github.com/rolling-scopes-school/fun-chat-server/tree/main) в отдельном терминале

```bash
cd path-to-server-folder
npm install
npm run start
```

## Функциональность

- Авторизация пользователя с валидацией логина и пароля (регистрация и логин здесь не разделены)
- SPA с роутингом и управлением историей браузера
- Основная страница доступна только авторизованным пользователям
- Общий список пользователей с отображением онлайн-статуса
- Отображение количества непрочитанных сообщений от пользователей
- Диалоги 1-на-1 с полной историей переписки
- Поддержка реального времени через WebSocket
- Отправка сообщений по Enter или кнопке
- Индикация доставленных и прочитанных сообщений
- Разделение прочитанных/непрочитанных сообщений визуально
- Возможность редактирования и удаления своих сообщений
- Обработка потери соединения и повторной авторизации
- Описание приложения на странице About, доступной всем
- Адаптивный дизайн(от 1440px до 380px)
