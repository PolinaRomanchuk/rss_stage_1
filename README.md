# 🌀 Decision Making Tool

**Краткое описание:**  
SPA-приложение для случайного выбора одного из заданных вариантов на основе их веса (веса — вероятности).

**Ссылка на задание:**  
[Decision Making Tool](https://github.com/rolling-scopes-school/tasks/blob/master/stage2/tasks/decision-making-tool/README.md)

**Деплой:**  
[Открыть приложение](https://rolling-scopes-school.github.io/polinaromanchuk-JSFE2024Q4/decision-making-tool/)

---

## Технологии

- **Язык:** TypeScript
- **Фреймворк:** нет (vanilla JS + TypeScript)
- **Сборка:** Webpack
- **Роутинг:** SPA через URL
- **Стили:** CSS
- **Canvas:** для визуализации колеса выбора
- **Форматирование:** Prettier
- **Линтинг:** ESLint
- **Git хуки:** Husky
- **Деплой:** gh-pages

---

## Установка и запуск

1. **Клонировать репозиторий:**

```bash
git clone https://github.com/PolinaRomanchuk/rss-stage-1.git
cd rss-stage-1
```

2. **Перейти в ветку с проектом:**

```bash
git checkout decision-making-tool
```

3. **Перейти в папку проекта:**

```bash
cd decision-making-tool
```

4. **Установить зависимости:**

```bash
npm install
```

5. **Запустить в режиме разработки:**

```bash
npm run start
```

---

## Функциональность

- SPA с роутингом, работающим при прямом переходе и обновлении страницы
- Полноценный интерфейс для редактирования списка опций: добавление, удаление, изменение
- Поддержка сохранения и загрузки списка из .json
- Вставка списка из CSV-подобного формата
- Интерактивные модальные окна (пастинг, ошибки, предупреждения)
- Колесо выбора: сектора с весами и уникальными цветами, отображение названий, эффект вращения с easing-анимацией
- Возможность включения/отключения звука и сохранения состояния mute
- Продолжительность вращения задаётся пользователем
- Хранение состояния и списка опций в LocalStorage
- Обработка неизвестных маршрутов (страница 404)
- Адаптивный дизайн( от 640px до 1280px)
