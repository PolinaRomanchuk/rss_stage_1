# 🎄 Christmas Shop

**Краткое описание:**  
Адаптивный двухстраничный сайт интернет-магазина подарков к Рождеству. Включает главную страницу и каталог подарков. Использует макет из Figma, реализован без библиотек и фреймворков, с чистым JavaScript для интерактивности.

## Установка и запуск

1. **Клонировать репозиторий:**

```bash
git clone https://github.com/PolinaRomanchuk/rss-stage-1.git
cd rss-stage-1
```

2. **Перейти в ветку с проектом:**

```bash
git christmas-shop
```

3. **Перейти в папку проекта:**

```bash
cd christmas-shop
```

4. **Открыть файл index.html в браузере**

Можно дважды кликнуть по файлу либо запустить через Live Server в редакторе (например, VS Code)

## Функциональность

- Чистая верстка по [Figma](https://www.figma.com/design/zTB01BwWZVoXYK5atH3eZT/Christmas-Shop?node-id=0-1&p=f&t=GibiWHVrlOU7neLA-0), 100% Pixel Perfect
- Полная адаптивность от 1440px до 380px без горизонтального скролла
- JS-функциональность: переключения, интерактив, таймер обратного отсчета до нового года
- Фильтрация / сортировка по категориям / модальные окна
