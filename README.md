# 🧩 RSS Nonograms

**Краткое описание:**  
Реализация классической головоломки — нонограммы (пиксельный кроссворд), где игроку нужно по числовым подсказкам определить расположение чёрных клеток и открыть спрятанное изображение.

**Ссылка на задание:**  
[RSS Nonograms Task](https://github.com/rolling-scopes-school/tasks/tree/master/tasks/nonograms)

**Деплой:**  
[Открыть приложение](https://rolling-scopes-school.github.io/polinaromanchuk-JSFE2024Q4/nonograms/)

## Установка и запуск

1. **Клонировать репозиторий:**

```bash
git clone https://github.com/PolinaRomanchuk/rss-stage-1.git
cd rss-stage-1
```

2. **Перейти в ветку с проектом:** 
```bash
git checkout nonograms
 ```

3. **Перейти в папку проекта:**

```bash
cd nonograms
 ```

4. **Открыть файл index.html в браузере:**

Можно дважды кликнуть по файлу либо запустить через Live Server в редакторе (например, VS Code)

## Функциональность
-Классические нонограммы 5x5, 10x10, 15x15
-Возможность выбора уровня сложности и шаблона
-Заполнение ячеек: левая кнопка мыши — чёрный цвет, правая — крестик
-Подсказки по краям, разделители каждой пятой линии
-Таймер, отображение времени после победы
-Сохранение и восстановление последней игры
-Звуковые эффекты при действии и победе, которые можно отключить/включить
-Поддержка светлой/тёмной темы
-Таблица рекордов (последние 5 побед)
-Случайная игра по нажатию кнопки "Random"
-Кнопка "Решение" — заполнение правильным ответом (не считается победой)
