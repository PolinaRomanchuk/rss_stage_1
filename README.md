# 🏁 Async Race

**Краткое описание:**  
SPA-приложение, позволяющее управлять коллекцией управляемых автомобилей: создавать, удалять, изменять их, запускать гонки и отображать победителей с детальной статистикой.

**Ссылка на задание:**  
[Async Race](https://github.com/rolling-scopes-school/tasks/tree/master/stage2/tasks/async-race)

**Деплой:**  
[Открыть приложение](https://rolling-scopes-school.github.io/polinaromanchuk-JSFE2024Q4/async-race/#)

## Установка и запуск

1. **Клонировать репозиторий:**

```bash
git clone https://github.com/PolinaRomanchuk/rss-stage-1.git
cd rss-stage-1
```

2. **Перейти в ветку с проектом:**

```bash
git checkout async-race
```

3. **Перейти в папку проекта:**

```bash
cd async-race
```

4. **Установить зависимости:**

```bash
npm install
```

5. **Запустить в режиме разработки:**

```bash
npm run start
```

6. **Запустить серверное приложение:**

Необходимо также клонировать и запустить [сервер](https://github.com/mikhama/async-race-api) в отдельном терминале

```bash
cd path-to-server-folder
npm install
npm run start
```

## Функциональность

**Garage:**
- Добавление, изменение и удаление автомобилей
- Выбор цвета машины из палитры
- Просмотр автомобилей по страницам (по 7 штук на страницу)
- Генерация 100 случайных машин
- Кнопки запуска и остановки двигателя для каждой машины
- Анимация движения автомобиля
- Запуск гонки между всеми машинами текущей страницы
- Сброс всех машин на старт
- Отображение имени победителя

**Winners:**
- Таблица с победителями: машина, имя, количество побед, лучшее время
- Сортировка по победам и по времени
- Пагинация
- Адаптивный дизайн(до 500px)
