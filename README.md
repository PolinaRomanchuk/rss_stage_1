# 🎮 Simon Says

**Краткое описание:**  
Игра Simon Says — это тренировка памяти, в которой игроку нужно воспроизвести последовательность символов, показанную компьютером. В игре 5 раундов и 3 уровня сложности (только цифры, только буквы, буквы и цифры). Пользователь может использовать как экранную, так и физическую клавиатуру.

## Функциональность

- 3 уровня сложности: easy — только цифры, medium — только буквы, hard — буквы и цифры
- 5 раундов с усложнением: длина последовательности растёт на 2 символа с каждым раундом
- Экранная и физическая клавиатура (ввод с обеих)
- Эмуляция ввода последовательности с задержкой и подсветкой
- Подсказка уровня и счётчик раундов
- Отключение ввода во время показа последовательности
- Кнопка "Repeat" — одноразовое повторение последовательности
- "New Game" — перезапуск с сохранением выбранного уровня сложности
- Автоматическая проверка введённой последовательности: немедленное завершение при ошибке, поздравление при правильном вводе
- Кнопка "Next" — переход к следующему раунду
- Финальное сообщение после победы в 5 раунде
- Адаптивный дизайн: поддержка десктопа(1440px <= width), планшета(768px <= width < 1440px) и мобильных устройств (360px <= width < 768px)
