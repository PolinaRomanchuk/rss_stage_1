## Code Review

- **Тип задачи**: анализ и ревью чужого кода
- **Описание**:  Задача заключалась в проведении кода-ревью существующего приложения — **Movie App**. В рамках задания необходимо было:
- Ознакомиться со структурой и логикой проекта
- Выявить недочёты в архитектуре, читаемости и стиле кода
- Оценить соблюдение лучших практик JavaScript
- Оставить развёрнутые комментарии и предложения по улучшению прямо в Pull Request

- ветка: code-review
- [задание](https://github.com/rolling-scopes-school/tasks/tree/master/stage2/tasks/code-review)
